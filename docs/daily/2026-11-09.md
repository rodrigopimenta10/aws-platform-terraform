# 2026-11-09: M0.1 Shared conventions (`modules/labels`)

**Built today:** a `labels` module that computes the name prefix and the standard tag map, plus ADR 0002 explaining the naming and tagging rules.
**Files:** [modules/labels](../../modules/labels/), [tests](../../modules/labels/tests/labels.tftest.hcl), [ADR 0002](../adr/0002-naming-and-tagging.md).

## What it is, in plain terms
A **tag** is a key/value label you attach to an AWS resource. AWS itself ignores most tags, but you and your
tooling don't: cost reports group by tag ("what did `project=platform` cost?"), IAM policies can allow or deny
based on tags, and clean-up scripts find leftovers by tag. A **name** is what you see in the console and in
ARNs (Amazon Resource Names, the unique IDs of AWS resources). Many resources can't be renamed later, so
the naming scheme has to be right before the first resource exists.

Terraform concepts used: a **module** (a reusable folder of `.tf` files), **locals** (named computed values),
**variable validation** (rejecting bad input at plan time) and **outputs**.

## How it works
The module has no resources at all, only inputs, a few `locals`, and outputs.

```hcl
prefix = "${var.project}-${var.environment}"

tags = merge(var.extra_tags, {
  project     = var.project
  environment = var.environment
  owner       = var.owner
  managed-by  = "terraform"
})
```

`merge` lets later maps win on duplicate keys. Putting the standard tags last means a caller's `extra_tags`
can add tags but never override the four required ones. `components = ["vpc", "flow-logs"]` becomes
`names = { vpc = "platform-dev-vpc", flow-logs = "platform-dev-flow-logs" }`.

## Why it's built this way
- **Central module vs. copy-paste:** copy-pasted conventions drift. One module means a rule change is one edit.
- **Closed list for `environment`:** `prod` vs `production` would otherwise become two cost buckets.
- **`project` capped at 20 chars:** load balancers and target groups cap names at 32, and the environment and
  component also have to fit.
- **`owner` can't look like an email:** tags leak into billing exports, and this repo is public.
- **Use with `default_tags`:** set `tags` once on the AWS provider and every taggable resource inherits them.
- Cost: nothing, there are no resources. Security: validation keeps odd characters out of names and tags.

## How it's tested
`mock_provider "aws"` with `command = plan` (no network). Nine runs: prefix and tags, component names, extra
tags merging without overriding, and one `expect_failures` run per validation rule (environment, uppercase
project, trailing hyphen, email owner, bad component, `aws:` tag prefix). There is **no Moto test**: Moto
emulates AWS resources and this module has none. Later modules will consume it in their own Moto tests.

## Try it yourself (10-15 min)
Add a validation rule that rejects `project = "aws"` (a name starting `aws` is confusing next to AWS's reserved
`aws:` tag prefix), and a test run with `expect_failures = [var.project]` proving it. Check with
`scripts/check.sh modules/labels`.

## Interview questions
<details><summary>1. Why use `default_tags` on the provider instead of tagging each resource?</summary>

It applies tags to every taggable resource automatically, so nobody forgets. Resource-level tags still merge
on top. Caveat: tags on resources created outside the provider (for example autoscaling instances) need
separate handling.

</details>

<details><summary>2. Why might changing a naming prefix later be painful?</summary>

Many AWS resources (S3 buckets, IAM roles, load balancers) can't be renamed, so Terraform destroys and
recreates them. That can mean downtime or data loss, which is why the scheme is decided first and recorded in
an ADR.

</details>

<details><summary>3. How do tags help with cost control?</summary>

Once a tag is activated as a cost allocation tag in AWS Billing, Cost Explorer and billing reports can group
spend by it, for example per project or environment. Activation is a manual billing step, and only costs after
activation are tagged.

</details>
